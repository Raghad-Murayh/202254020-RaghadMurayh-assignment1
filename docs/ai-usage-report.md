# AI Usage Report

## AI Tool Used

I used ChatGPT as the AI tool while developing my personal portfolio website.

## How I Used AI

I used ChatGPT throughout the assignment for several purposes:

- To understand the assignment requirements and what was expected in the portfolio website.
- To understand how to organize the GitHub repository and project files.
- To generate a starting structure for the HTML, CSS, and JavaScript.
- To help create a responsive layout for desktop and mobile screen sizes.
- To implement a light and dark mode feature using JavaScript.
- To troubleshoot issues with project images, including image paths and image cropping.
- To understand Git and GitHub concepts such as commits, pushing, syncing, and repository structure.
- To help organize the README and other project documentation.

## How I Reviewed and Modified AI Suggestions

I did not use the AI-generated content without reviewing it. I tested the code in the browser and modified it to fit my portfolio and the assignment requirements.

Some of the changes I made included:

- Replacing placeholder information with my own information.
- Adding project images.
- Changing the project descriptions.
- Adjusting the website content and layout.
- Choosing dark mode as the JavaScript interactive feature.
- Modifying the image styling so that the full project screenshots are displayed without being cropped.
- Organizing the project files and folders based on my repository structure.

## Benefits of Using AI

ChatGPT helped me understand parts of the assignment that were initially unclear. It also helped me identify problems in my code and understand how HTML, CSS, and JavaScript work together.


## Challenges and Limitations

Some AI suggestions did not exactly match my project structure or what I wanted for the website. For example, file paths and image styling needed to be changed to match my actual files.

## What I Learned

Through this assignment, I learned more about structuring a web project, creating a responsive website, using CSS for different screen sizes, and using JavaScript to add interactivity such as light and dark mode.

I also gained more experience using Git and GitHub to organize files, create commits, and keep track of changes.
