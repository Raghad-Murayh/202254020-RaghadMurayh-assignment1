# Technical Documentation

## Project Structure

- `index.html`: Contains the structure and content of the portfolio website.

- `styles.css`: Contains the website design, layout, responsive design, and light/dark mode styles.

- `script.js`: Contains the JavaScript used for the light/dark mode feature.

- `assets/image/`: Contains the images used for the projects.

- `docs/`: Contains the AI usage report and technical documentation.

## Technologies Used

The portfolio website was developed using HTML, CSS, and JavaScript.

## Main Features

- About Me, Projects, and Contact sections.

- Navigation links that allow users to move between sections.

- Smooth scrolling between sections.

- Two project cards with images and descriptions.

- Responsive layout for desktop and mobile screen sizes.

- Light and dark mode button.

- Contact form with name, email, and message fields.

## Testing

The website was tested by checking the navigation links, project images, light/dark mode button, and contact form fields.

The browser window was also resized to make sure the website layout adjusts correctly for smaller screen sizes.
